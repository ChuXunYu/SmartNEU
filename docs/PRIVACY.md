# 隐私说明

本文说明 日在NEU 会接触哪些数据、保存在哪里、保留多久，以及如何删除。

## 原则

- 只访问用户**本人**的校园账号数据；
- 不在服务器端收集、上传或分析任何用户数据；
- 不接入广告、统计 SDK 或第三方分析服务；
- 不把凭据写入日志、仓库或导出文件。

## Android 端保存的数据

| 数据 | 位置 | 形式 | 保留 |
| --- | --- | --- | --- |
| 登录 ticket / Cookie | `SharedPreferences("neu")` | 应用私有 | 直到退出登录或清除数据 |
| 展示用账号信息 | 同上 | 应用私有 | 同上 |
| SMTP 专用密码 | `SharedPreferences("neu-lite-secure")` | Android Keystore AES-GCM | 直到用户清除 |
| 校园乐跑链接 | 同上 | Android Keystore AES-GCM | 直到链接失效或清除 |
| 课表/成绩等缓存 | WebView `localStorage` | 应用私有 | 单一键覆盖，随刷新更新 |
| 邮箱正文缓存 | WebView `localStorage` | 应用私有 | 上限约 1 MB / 30 封 |
| 导出 CSV | 应用外部文件目录 | 明文 | 每类仅保留最新一份 |
| WebView 资源缓存 | 系统 WebView 目录 | 系统管理 | 超过 24 MB 自动清理 |

应用设置 `android:allowBackup="false"`，不参与 Android 云备份。

## 桌面端保存的数据

`state.json` 默认位于项目目录或 `NEU_STATE` 指定位置：

- ticket、Cookie、设备标识；
- 展示用账号信息（用户名、姓名、学号）；
- **不保存校园密码明文**。

文件在支持的平台上设为 `0600`，并已加入 `.gitignore`。

## 不会保存的数据

- 校园账号密码明文（Android 端仅保存 SMTP 专用密码与乐跑链接；桌面端不保存密码）；
- 短信验证码；
- 支付密码 / 银行卡信息；
- 邮箱正文的长期归档；
- 任何用于画像、统计或广告的数据。

## 网络请求

应用直接访问学校系统：

- `personal.neu.edu.cn` 门户与接口；
- `pass.neu.edu.cn` 统一身份认证；
- `jwxt.neu.edu.cn` 教务；
- `webvpn.neu.edu.cn` 校外访问；
- 邮箱、校园卡、网费、乐跑等学校子域。

项目本身不经过任何自建中转服务器。桌面端只监听 `127.0.0.1`。

## 权限

Android 端按需申请：

- 定位：校园乐跑 H5 / 校园服务页面；
- 相机：乐跑人脸相关页面；
- 文件选择：网页上传附件；
- 网络与通知：基础运行。

不申请后台定位、麦克风、通讯录、短信读取等权限。

## 删除数据

### Android

- 清除单个缓存：更多 → 清理网页资源缓存；
- 清除全部本地数据：系统设置 → 应用 → 日在NEU → 存储 → 清除数据；
- 彻底删除：卸载应用。

### 桌面端

删除 `state.json` 即可；如需保留登录态，先退出登录再删除。

## 导出文件

- 课表导出为**明文 CSV**；
- 请勿把导出文件、二维码截图或含个人信息的页面截图上传到公开 Issue。

## 第三方

- 学校各系统有自己的隐私政策；
- 二维码库 `qrcode.js` 在本地运行，不发起网络请求；
- 详见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
