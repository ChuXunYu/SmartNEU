# 故障排查

## 登录

### 登录后立即回到登录页

可能原因：

- TGT 已失效；
- 学校门户改了接口；
- 系统时间偏差过大。

处理：

1. 检查手机系统时间是否自动同步；
2. 退出登录后重新登录；
3. 仍失败时抓取错误提示（不要附带 Cookie/token）提交 Issue。

### 提示需要短信验证

学校对陌生设备会触发二次验证。按页面提示发送并填写验证码即可；勾选“信任本设备”可减少重复验证。

### 一直提示“会话失效”

- 确认只在一台设备上频繁切换账号；
- 退出登录后重新登录；
- 如仍复现，记录发生时间与操作路径。

## 校外访问 / WebVPN

### 校外打不开教务或邮箱

项目会按需自动走 WebVPN。若失败：

- 确认学校 WebVPN 本身可访问；
- 尝试切换网络后重试；
- 检查是否被系统代理/VPN 拦截。

### WebVPN 登录失败

WebVPN 使用独立的会话。退出 App 后重新登录，让 `webvpnLogin()` 重新建立连接。

## 校园乐跑

### 一直显示“正在准备校园乐跑”

`RunBinder` 会先直连门户，失败后自动切 WebVPN，超时时间分别为 25 秒和 45 秒。

排查：

1. 是否在校园网或 WebVPN 环境；
2. 门户是否能在浏览器打开；
3. 等待自动重试，或切换网络后重新打开；
4. 查看日志：

   ```powershell
   adb logcat -s RunBinder
   ```

日志中的 `vpn=false` 表示直连，`vpn=true` 表示 WebVPN。

### 打开乐跑提示链接失效

乐跑链接带 `token` 和 `sign`，会过期。App 会调用 `RunUrl.refresh()` 续签；若仍失败，清除链接后重新绑定：

- 更多 → 清理网页资源缓存；
- 或退出登录后重新登录再打开乐跑。

### 乐跑页面空白

- 乐跑 H5 需要定位/相机权限时，按页面提示授权；
- 检查 WebView 是否被系统省电策略限制；
- 切换网络后重试。

## 邮箱

### SMTP 发信失败

- 确认使用的是邮箱“客户端专用密码”，不是网页登录密码；
- 检查是否开启 SMTP 服务；
- 附件最多 3 个、合计 12 MB；
- 部分网络会拦截 465/587 端口，切换网络重试。

### 正文一直加载

邮箱正文按需加载并缓存。若长时间无响应：

- 检查网络；
- 退出邮箱页后重新进入；
- 清理网页资源缓存后重试。

## 校园卡 / 网费

### 二维码不刷新

- 校园卡页每 10 秒自动刷新；
- 页面进入时会临时提高屏幕亮度，离开后恢复；
- 若提示鉴权失败，重新登录。

### 充值页面打不开

支付页使用独立 WebView 与 Cookie。确认已登录且网络可访问支付平台；不要在同一时间多端操作支付会话。

## 构建

### `aapt2` / `d8` 找不到

`build.ps1` 中的 `$sdk` 路径不正确，或未安装 `build-tools;36.0.0`。

### `javac` 版本错误

需要 JDK 11 或更高。检查：

```powershell
java -version
javac -version
```

### 签名校验失败

升级安装必须使用同一签名。不要替换 `neu-lite.keystore`；该文件已被 `.gitignore` 排除，需自行备份。

### 安装时提示“已安装更高版本”

Android 默认禁止降级安装。处理方式：

- 卸载当前版本后安装；
- 或使用 `adb install -r -d`；
- 检查手机分身、工作资料、第二用户中是否还有旧版本。

## 数据与缓存

### 缓存占用过大

- 更多 → 清理网页资源缓存（只清 WebView 资源，不影响登录）；
- 导出文件每类只保留最新一份；
- 如仍异常，记录版本与操作路径后提交 Issue。

### 想彻底清除本地数据

- 系统设置 → 应用 → 日在NEU → 存储 → 清除数据；
- 或卸载重装。

清除后需要重新登录，已保存的 SMTP 密码和乐跑链接也会丢失。

## 提交 Issue 前

请附：

- App 版本 / 提交号；
- 机型与 Android 版本；
- 复现步骤；
- 错误提示或日志片段（**不要包含学号、密码、TGT、Cookie、token**）。

安全问题请按 [SECURITY.md](../SECURITY.md) 私下报告。
